客户端怎么配置第三方 API

Cherry Studio · NextChat · LobeChat · Cline 通用步骤　｜返回比价指南

所有客户端都只认三个值：base_url、api_key、model。配不通几乎都是这三个里有一个不对。

一、先拿到三个值

值从哪来长什么样
base_url站点文档或控制台https://站点域名/v1
api_key控制台 → 令牌/API Keys → 新建sk- 开头的一串
model站点模型列表如 deepseek-v4.1-flash-1017、glm-5.3、kimi-k3

注意：模型名必须一字不差，包括连字符和版本号。自己猜的名字 100% 会报 model not found。

二、Cherry Studio

  1. 设置 → 模型服务 → 添加提供商（选 OpenAI 兼容 / 自定义）
  2. API 地址填 base_url
  3. API 密钥填 sk-...
  4. 点「获取模型列表」，或手动添加模型名
  5. 回到对话界面，选刚加的模型

常见问题：获取列表失败多半是 base_url 少了 /v1；列表能拉到但对话报错，检查模型是否在当前分组开放。

三、NextChat（ChatGPT-Next-Web）

  1. 设置 → 自定义接口（Custom Endpoint）
  2. 接口地址填 base_url
  3. API Key 填 sk-...
  4. 模型下拉框里「自定义模型」填模型名，多个用逗号分隔

注意：NextChat 会在 base_url 后面自动拼 /chat/completions，所以不要自己写全路径。

四、LobeChat

  1. 设置 → 语言模型 → OpenAI（或自定义提供商）
  2. 填入 base_url 与 API Key
  3. 在「模型列表」里手动加入模型 ID
  4. 开启「使用客户端请求」以免服务端代理造成额外超时

五、Cline / Roo Code（VS Code 插件）

  1. 选择 API Provider 为 OpenAI Compatible
  2. Base URL 填 base_url
  3. API Key 填 sk-...
  4. Model ID 填准确模型名

如果要接 Claude Code 这类走 Anthropic 协议的工具，需要站点提供 Anthropic 兼容接口，配置方式不同，见 Claude Code 配置教程。

六、多模型怎么组织

建议按用途建多套配置，而不是一套里塞所有模型：

用途模型选择思路
写代码 / 改 bug选响应快、代码能力强的 Flash 类
中文写作、翻译选中文语感好的
长文档分析选上下文窗口大的
批量任务选单价最低的，并做好失败重试

七、配完连不上，按这个顺序查

  1. 用 curl 直接打一次 /v1/models，确认 key 和 base_url 本身是对的
  2. curl 通了但客户端不通 → 客户端路径拼接问题（多写了路径或少了 /v1）
  3. 客户端报 model not found → 模型名不对
  4. 都通但很慢 → 上游拥堵，换模型或换站
  5. 偶发失败 → 加自动重试，不要一次失败就判定站点不可用

报错含义逐个查：AI API 常见报错大全。
