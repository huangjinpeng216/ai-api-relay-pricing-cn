团队采购 AI API 要问清楚的 12 个问题

个人试用到公司报销，中间的差别不是价格，是这 12 件事　｜返回比价与选站指南

一句话版本：个人只看「能不能调通、便不便宜」；公司还要看「能不能报销、出问题谁负责、数据去哪了、不用了怎么退」。

这 12 个问题按顺序问，能筛掉大部分不适合团队使用的服务商。每一个都给出「该听到什么答案」和「红旗信号」。

一、商务相关（4 个）

1. 能开发票吗？什么类型、几个点？

该听到的红旗信号
明确说出发票类型（增值税普通/专用）、税率、开票周期含糊其辞，或说「这个要问一下」然后没下文

为什么重要：没有发票，这笔支出在公司账上就是「个人垫付无法报销」，团队用不起来。

2. 付款方式有哪些？支持对公转账吗？

个人用支付宝微信就够了，团队通常需要对公转账并走采购流程。

红旗：只支持个人扫码充值，且不能提供收款方公司主体信息。

3. 单价会变吗？变之前会通知吗？

倍率型服务最常见的问题是「悄悄调倍率」。问清楚：

  • 当前倍率是多少，按什么周期复核
  • 调整前是否提前通知，提前多久
  • 已充值的余额是否按新倍率消耗

4. 余额怎么结清？不用了怎么处理？

这是团队采购最该问但最少人问的一条。

预付费服务的余额本质是对服务商的债权。要问清三件事：

  • 余额能否结清或转出，条件是什么
  • 不能结清的话，余额有效期多久
  • 服务停止运营时，余额如何处理

红旗：「永久有效」这种承诺——没有主体支撑的永久承诺等于没有承诺。

二、技术相关（4 个）

5. 支持哪些协议？我们要用的工具适配吗？

你的工具需要的协议
Claude Code / Codex CLIAnthropic Messages（/v1/messages）
Cursor / Cline / NextChatOpenAI（/v1/chat/completions）
Gemini 生态工具Gemini（/v1beta/models）

只支持一种协议的服务商，会在你换工具时变成障碍。

6. 并发上限是多少？超了会怎样？

要问具体数字，不要接受「足够用」这种回答。

  • 每分钟请求数（RPM）和每分钟 token 数（TPM）上限
  • 超限是排队、报 429、还是静默降速
  • 能不能申请提额，条件是什么

7. 出故障时怎么通知？有没有状态页？

团队场景下，「坏了没人说」比「坏了」更麻烦——用户会以为是自己的问题。

该听到的红旗信号
有状态页 / 公告渠道，故障时主动通知，恢复后说明原因只能靠用户自己发现调不通

顺便说一个判断技巧：未鉴权访问 /v1/models 应该返回 401。返回 404 说明路由丢失，返回 000 说明服务不可达。这一条 10 秒能测出来。

8. 调用日志能查多久？能导出吗？

团队要做成本分摊和问题追溯，日志是唯一依据。

  • 能查到每次调用的 token 数、时间、模型名吗
  • 日志保留多久
  • 能不能按 key / 成员 / 项目分开统计
  • 能不能导出 CSV

三、合规与数据（2 个）

9. 我的 prompt 和返回内容会被留存吗？留多久？

这个问题必须得到明确答复，不接受「我们不会看」。

要问的是技术事实，不是承诺：

  • 请求内容是否落盘
  • 落盘的话保留多久、谁能访问
  • 是否用于任何形式的训练或分析

10. 上游是谁？是自己的账号池还是转售？

这决定了两件事：数据经过几手，以及服务中断的概率。

类型特征风险
自有官方账号能说明上游渠道和使用条款较低，但受官方政策影响
多层转售说不清上游是谁任一环节出问题就断，数据路径不可知

四、退出与依赖（2 个）

11. 如果我们要换服务商，迁移成本有多大？

好消息是 API 类服务迁移成本通常很低——只要对方用标准协议。所以这条的实质是问：

  • 是否用标准 OpenAI / Anthropic 协议（是的话改个 base_url 就能迁）
  • 有没有私有扩展字段，用了就锁死
  • 模型名是否与官方一致（不一致的话迁移要改代码）

12. 你们公司主体是什么？能提供营业执照吗？

团队采购走合同流程时必须有明确的法律主体。

红旗：只有个人账号收款、无法提供主体信息。这种情况下合同签不了，报销也走不通。

可以直接复制的提问清单

你好，我们在评估团队接入，想确认几件事：

商务
1. 能否开具增值税发票？类型和税率？
2. 支持对公转账吗？收款主体名称是什么？
3. 当前倍率多少？调整前会提前通知吗？
4. 余额能否结清或转出？不能的话有效期多久？

技术
5. 支持 OpenAI / Anthropic / Gemini 哪几种协议？
6. RPM 和 TPM 上限分别是多少？超限的表现是什么？
7. 有状态页或故障通知渠道吗？
8. 调用日志能查多久？可以按 key 分开统计并导出吗？

合规
9. 请求和响应内容是否留存？留存多久？是否用于训练？
10. 上游渠道是自有账号还是转售？

退出
11. 模型名是否与官方一致？迁移时是否只需改 base_url？
12. 能否提供营业执照等主体信息用于签约？

一张对照表：个人 vs 团队

关注点个人自用团队/公司
价格越低越好可预测比低更重要
凭证不需要必须有发票
故障自己能等要能对外解释
数据不太在意必须问清流向

最后一句：这 12 个问题问下来，你大概能判断出对方是个什么规模的团队。

能立刻答出 8 个以上的，通常有一套完整的运营流程；答不上来的，不是不能合作，但你要清楚自己在承担什么。
