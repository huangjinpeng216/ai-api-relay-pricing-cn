一、先搞清楚：你的工具用哪种协议

工具使用的协议需要什么
Claude CodeAnthropic Messages站点必须提供 Anthropic 兼容接口
CursorOpenAI 或 Anthropic（可切）OpenAI 格式最通用
Cline / Roo CodeOpenAI 或 Anthropic同上
NextChat / LobeChat / Cherry StudioOpenAI填 base_url 即可

关键点：只提供 OpenAI 格式的站点，Claude Code 用不了。这就是为什么选站时要看「双协议」。

二、Claude Code 的两种配法

方式一：环境变量（推荐，最稳）

# macOS / Linux
export ANTHROPIC_BASE_URL="https://你的站点域名/api"
export ANTHROPIC_AUTH_TOKEN="你的 key"
claude

# Windows PowerShell
$env:ANTHROPIC_BASE_URL="https://你的站点域名/api"
$env:ANTHROPIC_AUTH_TOKEN="你的 key"
claude

注意：不同中转站的路径前缀不一样，常见的是 /api 或 /v1，以站点文档为准。

方式二：配置文件

在用户目录下创建 ~/.claude/settings.json：

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://你的站点域名/api",
    "ANTHROPIC_AUTH_TOKEN": "你的 key"
  }
}

四、报错对照表

报错真实原因怎么修
401 UnauthorizedKey 无效，或 base_url 路径不对检查 key 有无空格；确认路径前缀
404 Not Found路径多了/少了前缀试 /v1、/api 两种
model not found模型名不匹配，或该分组无权限复制站点的准确模型名
429 Too Many Requests并发或额度超限降低并发，查余额
能连但输出很慢上游拥堵或模型选错换 Flash 类模型试

五、两个容易踩的坑

  • 把 key 写进代码提交。推到 GitHub 后几分钟内就会被爬虫扫到，余额可能被刷光。一律用环境变量或本地配置文件，并把配置文件加进 .gitignore。
  • 只看倍率不看协议。买了只支持 OpenAI 格式的站，结果 Claude Code 用不了，钱白充。下单前先确认双协议。

六、验证是否配好

最快的验证方式：发一句最简单的提问，看是否有正常回复。有回复说明链路通了；报错就按上面的对照表查。

更严谨的做法是跑一段需要多步推理的 prompt，确认输出质量和官方一致——这能顺便验证是不是被掺水降智。
