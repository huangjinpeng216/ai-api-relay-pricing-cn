AI API 中转站避雷指南

跑路 · 掺水降智 · 偷偷限流 · 扣费不透明　｜比价与选站总览

中转站这个市场的信息极度不对称：你付了钱，但看不到背后的上游。下面五类坑，按「踩了之后损失从大到小」排序，每一条都给出可执行的识别方法。

坑一：跑路（损失最大）

表现：站点突然打不开、域名过期、余额清零、客服消失。通常发生在你刚充了大额之后。

识别方法：

  • 看域名注册时间——建站不到 3 个月的，不要充大额
  • 看是否有公开的运营痕迹（更新日志、用户群、社群反馈）
  • 看充值档位——只推大额套餐、刻意引导高充的，风险更高

防御：一次只充够两周用量，用完再充。这是唯一真正有效的办法。

坑二：掺水降智（最隐蔽）

表现：宣传是满血模型，实际把你的请求转发给小模型，或者降低 max_tokens、截断上下文。账单照收，效果打折。

识别方法：准备一段需要多步推理的 prompt（不要用「你好」这种），在官方和该站各跑一次，对比：

  • 输出质量是否明显下降
  • 是否容易答错简单逻辑题
  • 首字延迟是否异常快（小模型更快）
  • 同样 prompt 连续跑 5 次，结果是否高度趋同（降级模型多样性差）

坑三：偷偷限流

表现：并发一高就 429，或者白天正常、晚上疯狂超时。宣传「不限并发」但实际有隐性阈值。

识别方法：用脚本发 10 个并发请求，看失败率和延迟分布。单次调用测不出这个问题。

坑四：扣费不透明

表现：看不到每次调用的 token 数；只给一个总额；倍率在账单里不体现。

识别方法：充最小额，跑 10 次已知长度的请求，自己算理论消耗，和实际扣费对比。差得多就是有问题。

防御：只选能查调用日志的站。

坑五：Key 泄露与盗刷

表现：余额在半夜被刷光，日志里出现你没发过的请求。

识别方法：定期看调用日志的时间分布。异常时段（凌晨 2-5 点）的大量请求要警惕。

防御：

  • Key 只放环境变量，绝不提交进代码仓库
  • 不同项目用不同的 Key，方便单独吊销
  • 给 Key 设额度上限
  • 发现泄露立刻删 Key 重建

坑六：跑分很好但实际不行

表现：官网挂着一堆「可用率 99.9%」「平均延迟 200ms」的指标，你自己用起来却经常超时。

为什么：那些数字可能是挑最好的时段测的，也可能是别家数据抄来的。中转站的延迟取决于上游，它自己控制不了。

识别方法：别看它给的数字，自己测三天的失败率和 P95 延迟。样本太小的话，测不出高峰期的表现。

坑七：客服靠猜，出问题没人认

表现：只有一个 QQ 群或 TG 群，没有工单系统；出问题只能群里刷屏问，回复是「重启试试」「你网络问题」。

为什么：这类站通常是单人运营，白天上班晚上维护，没有精力做售后。

识别方法：充值前先在群里问一个具体的技术问题（比如「你们 Anthropic 端点支持流式吗」），看回复质量。答不上来或敷衍的，出问题时也别指望。

一份 20 分钟的验证流程

上面七个坑，用下面这套流程能筛掉大部分。顺序不能乱：

步骤做什么看什么
1查域名注册时间WHOIS，不到 3 个月的不充大额
2充最小额度能不能充、到账快不快
3拉 /v1/models模型列表和宣传是否一致
4跑多步推理对比输出质量和官方差多少
5发 10 个并发失败率、延迟分布
6核对账单自己算的理论值和实际扣费差多少
7查调用日志有没有 token 数、时间、模型名

七步都过再考虑加量。任何一步明显不对，换下一家就行——供给充足，没必要赌。

踩坑之后怎么办

  1. 先止损，别先理论。立刻把余额用完或申请退，同时把调用切到备用服务。争论期间损失还在扩大。
  2. 留证据。调用日志、账单截图、报错原文、对方回复。这些是后面沟通或投诉的依据。
  3. 判断值不值得追。余额只有几十块，追的时间成本远超损失。把精力放在换站上更划算。
  4. 记录结论。把这家站的问题写下来，避免半年后忘了又充一次。

常见问题

Q：怎么快速判断一个站是不是「掺水」？

准备一段需要多步推理的 prompt（不要用「你好」这种），在官方和该站各跑一次。对比三点：结论正确率、推理过程完整度、首字延迟。延迟异常快且质量下降，基本就是转发到小模型了。

Q：便宜站真的会跑路吗？

会，而且是常态而非例外。这类服务的上游渠道不稳定、利润率薄，一旦上游断供或成本上涨，直接关站是最省事的处理方式。所以「一次只充两周用量」不是胆小，是行业基本常识。

Q：平台跑路了能追回钱吗？

基本不能。预付余额在法律上属于对服务商的债权，对方主体消失后追偿成本远超金额本身。唯一的防御是在充值时就把损失上限控制住。

Q：有没有完全安全的用法？

没有。只有把风险控制在可承受范围的用法：小额、勤充、留日志、备一家。做到这四条，就算踩坑也就是几十块钱的事。

Q：官方直连是不是就没这些坑？

官方没有「跑路」和「掺水」问题，但有另外的问题：需要外币卡、价格高、部分地区访问受限。选哪种取决于你更怕哪种风险，见 中转站 vs 官方直连。

最后一句

没有「绝对安全」的中转站，只有把损失控制在可承受范围的用法：小额、勤充、留日志、备一家。按这个习惯用，就算踩坑也只是几十块的事。
