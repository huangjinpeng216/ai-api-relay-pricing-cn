## 一、先理解「倍率」

LLM API 按 token 计费。官方价格以美元计，所以国内用户第一道门槛是外币信用卡。

中转站的本质是一层代理：你充人民币，它用上游额度帮你调用。价格用「倍率」表示：

| 倍率 | 含义 | 例：官方 $1 的量 |
|---|---|---|
| 0.1x | 官方价 1 折 | 付 $0.1 |
| 0.15x | 官方价 1.5 折 | 付 $0.15 |
| 0.5x | 官方价一半 | 付 $0.5 |

**2026 年市场行情大致在 0.15x ~ 0.5x。** 低于 0.1x 的要格外留意：要么上游来路不明，要么会在别处省成本（降级模型、限流、跑路）。

## 二、选站五项标准（比价格重要）

### 1. 稳定性
最容易被忽略、但最贵。便宜的站天天 502，你搭进去的时间和 token 成本远超省下的钱。
**测法**：充最小额度，连续用三天，看有没有超时和 502。

### 2. 是不是满血模型
有些站宣传完整版，实际降级成小模型。
**测法**：问一个需要长链条推理的问题，对比回答质量和延迟。

### 3. 协议兼容
只支持 OpenAI 格式的，Cursor、Claude Code 这类工具用不了。
**双协议（OpenAI + Anthropic）** 最省事。

### 4. 用量明细
能不能看到每次调用的 token 数、时间、模型名。出问题时这是唯一排查依据。

### 5. 支付方式
支付宝 / 微信直充的，比要外币卡的省一大截麻烦。

## 四、配置三步（OpenAI 兼容客户端通用）

不管是 NextChat、LobeChat、Cherry Studio 还是 Cline，配置项都是这三个：

| 项 | 填什么 |
|---|---|
| Base URL | 站点 API 地址 + `/v1` |
| API Key | 控制台里 `sk-` 开头那串 |
| 模型名 | 必须和站点列出的完全一致，一个字符都不能错 |

**两个最常见报错：**

| 报错 | 原因 |
|---|---|
| `401 Unauthorized` | Base URL 少了 `/v1`，或 Key 复制时带了空格 |
| `model not found` | 模型名拼错，或该模型在你当前分组不可用 |

## 五、避坑清单

- **不要一次充太多。** 中转站跑路是真实风险。建议一次充够两周用量，用完再充。
- **API Key 别提交进代码。** 推到 GitHub 后几分钟内会被爬虫扫到，余额可能被刷光。用环境变量。
- **先用小额度测，再上生产。** 批量任务前先跑十次调用，看延迟和成功率。
- **别信「永久有效」「永不封号」这类承诺。** 上游政策一变，谁都保证不了。
- **留好调用日志。** 出问题时这是唯一的证据。
