二、查的时候注意三件事

1. 输入和输出是分开定价的，而且差很多

DeepSeek Flash 输入 $0.15、输出 $0.60，输出是输入的 4 倍。只看到「一个价格」就说明这篇资料不完整。

2. 缓存命中价经常被忽略

DeepSeek Flash 缓存命中价 $0.003，未命中 $0.15 —— 差 50 倍。

多轮对话里每轮都重发系统提示词的话，你一直在按未命中价付费。合理使用缓存是最大的一笔省钱空间，比换平台省得多。

3. 峰谷价差一倍

DeepSeek 区分高峰期和低谷期，低谷价是高峰的一半。高峰时段为周一至周五 UTC 01:00–04:00 和 06:00–10:00（中国法定节假日除外）。

批量任务挪到低谷时段，价格直接减半，没有任何代价。

四、怎么用命令行批量核对

如果只是看一两家的价格，打开网页最快。要定期核对，可以用脚本：

# DeepSeek 定价页是静态 HTML，直接抓取就能取到数字
curl -sL "https://api-docs.deepseek.com/quick_start/pricing/" \
  | grep -oE '\$[0-9]+\.[0-9]+' | head -20

GLM 和 Kimi 的定价表是前端渲染的，直接 curl 只能拿到导航。需要用浏览器渲染：

// Playwright：渲染后取表格
const page = await browser.newPage();
await page.goto('https://open.bigmodel.cn/pricing', { waitUntil: 'networkidle' });
const rows = await page.evaluate(() =>
  [...document.querySelectorAll('table tr')].map(tr =>
    [...tr.querySelectorAll('th,td')].map(c => c.innerText.trim())));

五、识别不靠谱的价格资料

特征说明
没有抓取日期价格随时变，没日期的数字无法判断是否过期
没有官方来源链接无法追溯，可能是编的或从别处抄的
只有一个总价忽略输入/输出分开计价，用它算账单会差几十个百分点
不提缓存命中价漏掉了最大的省钱变量
换算成统一币种但不给汇率你不知道它按什么汇率算的，无法复现

本站的做法：所有价格标注抓取日期和官方来源链接，不做汇率换算（美元就是美元，人民币就是人民币），并在这里记录每次核查结果。

即便如此，也请你自己核一次。价格会调整，而这一页会比你晚知道。
