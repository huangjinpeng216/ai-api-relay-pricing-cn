三、选站五项标准（重要）

1. 稳定性

充最小额度，连续用三天，看有没有 502、超时、突然断流。这一项权重最高。

2. 是否掺水降智

同一个需要多步推理的 prompt，在官方和该站各跑一次，对比输出质量、思考深度、首字延迟。差距明显 = 被降级成小模型。

3. 协议兼容

只支持 OpenAI 格式的，Claude Code 这类工具用不了。要多协议（OpenAI / Anthropic / Gemini）。

4. 用量明细

能不能查到每次调用的 token 数、时间戳、模型名。出事时这是唯一证据。

5. 支付方式

支付宝/微信直充的，比要外币卡的省一大截麻烦。

七、怎么自己验证一家站靠不靠谱

下面这套流程 20 分钟能跑完，比看任何推荐都可靠——包括看我们这篇。

  1. 充最小额度。不要一次充几百。
  2. 拉模型列表。用 /v1/models 看它实际提供哪些模型，和宣传是否一致。
  3. 跑对比测试。同一段需要多步推理的 prompt，官方跑一次、该站跑一次，对比输出质量和首字延迟。
  4. 压一下并发。发 10 个并发请求，看失败率和延迟分布。单次调用测不出限流问题。
  5. 核对账目。跑 10 次已知长度的请求，自己算理论 token 消耗，和实际扣费对比。
  6. 查调用日志。看能不能查到每次调用的 token 数、时间、模型名。

六步都过了再考虑加量。任何一步明显不对，就换下一家——这个市场供给充足，没必要赌。

八、常见问题

Q：为什么你不列一大堆站名？

因为中转站存活周期普遍不长。列出来的名单三个月后可能一半失效，反而误导人。给标准比给名单有用——上面那套验证流程可以拿去掉任何一家。

Q：倍率越低越好吗？

不是。倍率只是价格维度。明显低于市场行情的倍率，通常意味着上游来路不明或在别处省成本（降级模型、隐性限流）。实测下来，这类站的总成本往往更高，因为你要反复重试。

Q：0.1x 已经是最低了吗？

2026 年的市场行情大致在 0.15x 到 0.5x，0.1x 属于偏低的一档。低于 0.1x 的要格外留意——上游成本摆在那里，过低的价格必然在别处找补。

Q：个人用户需要关注合规吗？

自用和对外提供服务是两件事。自己调 API 做工具是一回事；面向公众提供生成式 AI 服务，在国内属于需要评估的经营活动。这一点和选哪家平台无关，取决于你拿它做什么。

Q：如果平台跑路了怎么办？

没有追回的办法，这是这类服务的固有风险。唯一有效的防御是：一次只充够两周用量，并保留一家备用。把可能的损失控制在可承受范围内。
