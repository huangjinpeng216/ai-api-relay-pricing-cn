一、先搞懂「倍率」

大模型 API 按 token 计费（输入、输出分别计价）。官方价格以美元计，所以国内用户第一道门槛是外币信用卡。

中转站的本质是一层代理：你用人民币充值，它用上游额度帮你调用。价格用「倍率」表示：

倍率含义官方 1 美元的量，你要付
0.1x官方价 1 折0.1 美元等值人民币
0.15x官方价 1.5 折0.15 美元等值人民币
0.5x官方价一半0.5 美元等值人民币

2026 年市场行情大致在 0.15x ~ 0.5x。低于 0.1x 的要格外留意：要么上游来路不明，要么会在别处省成本（降级模型、限流、跑路）。

二、选站五项标准（比价格重要）

1. 稳定性

最容易被忽略、但最贵。便宜的站天天 502，你搭进去的时间和 token 成本远超省下的钱。
测法：充最小额度，连续用三天，看有没有超时和 502。

2. 是不是满血模型

有些站宣传完整版，实际降级成小模型。
测法：问一个需要长链条推理的问题，对比回答质量和延迟。

3. 协议兼容

只支持 OpenAI 格式的，Cursor、Claude Code 这类工具用不了。多协议（OpenAI / Anthropic / Gemini）最省事。

4. 用量明细

能不能看到每次调用的 token 数、时间、模型名。出问题时这是唯一排查依据。

5. 支付方式

支付宝 / 微信直充的，比要外币卡的省一大截麻烦。

五、避坑清单

  • 不要一次充太多。中转站跑路是真实风险，建议一次充够两周用量。
  • API Key 别提交进代码。推到 GitHub 后几分钟内会被爬虫扫到，余额可能被刷光。用环境变量。
  • 先用小额度测，再上生产。批量任务前先跑十次调用，看延迟和成功率。
  • 别信「永久有效」「永不封号」。上游政策一变，谁都保证不了。
  • 留好调用日志。出问题时这是唯一的证据。

六、常见问题

Q：中转站和官方 API 有什么区别？

官方直连需要外币信用卡，按美元结算；中转站是第三方代理，人民币充值，把请求转发给上游。功能上兼容 OpenAI/Anthropic 接口规范，差别在价格、稳定性和上游来源。

Q：倍率越低越好吗？

不是。倍率只是价格维度。低于市场行情的倍率通常意味着上游来路不明或在别处省成本，实际用起来可能更贵。

Q：怎么验证是不是满血模型？

用同一段需要多步推理的 prompt，在官方和该站各跑一次，对比输出质量、思考深度和首字延迟。差距明显就是被降级了。

Q：支持 Claude Code / Cursor 吗？

取决于站点是否提供 Anthropic 兼容接口。只支持 OpenAI 格式的站点无法直接给 Claude Code 用。
